# Responsive project and service photographs

Generated by `node scripts/optimize-project-images.mjs` from public project galleries and local service photography. Originals are preserved. Each filename includes a source-content hash; this directory can be cached immutably. Source dimensions and variant URLs are recorded in `src/lib/responsive-image-manifest.json`.

After changing gallery source photos, regenerate the variants and manifest together. New, unmatched admin uploads continue to load directly from their original URL.
